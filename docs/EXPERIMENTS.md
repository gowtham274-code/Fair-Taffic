# Experiments

Scenarios (veh/h per entry side, `simulation/scenarios/demand.py`, untuned): low 100; medium 250; high 400; **uneven** N/E/S 150 and W 600. Demand is generated by our code from (scenario, seed), so every controller and backend sees identical traffic.

Controllers: `fixed_time` (30 s greens), `queue_greedy` (conventional adaptive rule), `marl_conventional` (RL, w_fairness = 0), `marl_fair`, `centralized_fair`, `federated_fair`.

Protocol: train seeds 0,1,2 (training episode seeds differ per episode); evaluate on separate seeds (default 101–103) with greedy policies; report mean ± std across pooled evaluation episodes — with few seeds the std is itself uncertain; don't over-interpret small differences.

Reproduce (needs SUMO):
```
python -m experiments.run_suite --scenarios low medium high uneven --seeds 0 1 2 --prefix suite
python -m experiments.compare_results --root storage/experiments --out reports/comparison
```
Every run directory holds `config.json`, `summary.json`, `eval_results.csv`, `train_log.csv`, `fl_rounds.json`, `agent_trace.csv`, checkpoints. Existing runs are never overwritten.
